# Telegram AI Subscriptions Monitoring Bot v1.0 🤖📈

Продвинутый, асинхронный Telegram-бот на **aiogram 3** и **Playwright** для автоматического мониторинга цен на цифровые подписки ИИ-сервисов на ключевых маркетплейсах (**FunPay**, **Plati.Market**, **GGSel**, **Playerok**).

Бот отслеживает ключевые слова, парсит предложения, конвертирует цены с учетом курса ЦБ РФ, находит минимальные цены по категориям (ChatGPT, Claude, Midjourney, Gemini, Perplexity, Copilot, Cursor и др.) и мгновенно оповещает администраторов о появлении выгодных предложений или демпинге цен.

---

## 🚀 Ключевые возможности v1.0

* ** Мультиплатформенный парсинг**: Одновременный сбор данных с 4 маркетплейсов (`FunPay`, `Plati.Market`, `GGSel`, `Playerok`).
* **⚡ Ручной запуск парсинга в 1 клик**: Возможность запустить внеочередную проверку цен прямо из меню бота.
* **📉 Настройка порога демпинга (`min_price_drop_usd`)**: Фильтрация уведомлений об изменении цен (присылать только если цена упала минимум на заданную сумму в $).
* **📊 Профессиональные Excel (.xlsx) отчеты**: Выгрузка стилизованных отчетов с цветовым выделением скидок, финансовым форматированием и интерактивными ссылками.
* **🔍 Быстрый поиск `/search`**: Команда прямого поиска по базе объявлений прямо из чата.
* **📈 Панель аналитики и статуса**: Оценка времени парсинга, физического размера SQLite БД, числа увиденных объявлений и курсов валют.
* **🛡 Автоматический диагностический вочдог (Watchdog)**: Отслеживание ошибок и отправка алармов при 3 подряд неудачных циклах.
* **🌐 Прокси-менеджер с авто-очисткой**: Поддержка HTTP/SOCKS прокси, фоновая проверка каждые 2 часа и удаление нерабочих IP.
* **🌙 Тихий час (DND) и утренний дайджест**: Задержка ночных уведомлений с отправкой единого сводного отчета утром.
* **💾 Бэкап и восстановление БД**: Скачивание и загрузка файла SQLite базы данных через Telegram.

## 🛠️ Технологический стек

* **Python 3.11+**
* **aiogram 3.22** — Telegram Bot API Framework
* **Playwright (async)** — Эмуляция Chromium для обхода динамических скриптов
* **openpyxl** — Генерирование стильных Excel (.xlsx) таблиц
* **BeautifulSoup4 & lxml** — Быстрый парсинг HTML ответов
* **APScheduler** — Асинхронный планировщик задач
* **SQLite3 (aiosqlite)** — Хранение настроек и истории цен в WAL режиме

## ⚙️ Переменные окружения (.env)

Создайте файл `.env` в корневой директории:

```env
BOT_TOKEN=your_telegram_bot_token
FIRST_ADMIN_ID=your_telegram_user_id

# (Опционально) Для развертывания на Render.com
RENDER_EXTERNAL_URL=https://your-app.onrender.com
PORT=8080
```

---

## 🐳 Развертывание на Render.com

1. Создайте **Web Service** в сервисе Render.com.
2. Выберите среду исполнения **Docker**.
3. Укажите переменные `BOT_TOKEN`, `FIRST_ADMIN_ID`, `RENDER_EXTERNAL_URL`.
4. Для предотвращения засыпания бесплатного инстанса подключите [UptimeRobot](https://uptimerobot.com) с проверкой каждые 5 минут по созданному URL.

## 📝 Команды бота (для администраторов)

* `/start` — Открыть главную панель управления.
* `/search <запрос>` — Быстрый поиск подписок (напр. `/search ChatGPT`).
* `/help` — Подробная справка по всем функциям.
* `/cancel` — Сброс любого текущего ввода данных.
